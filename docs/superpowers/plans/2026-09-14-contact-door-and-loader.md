# Contact Door + Loader Loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Contact stop opens like a door in the network and hands the visitor a contact card; the loader plays a short Higgsfield loop of the void behind the decoding wordmark.

**Architecture:** The door is a vertex-shader displacement added to the shared `drifted()` GLSL used by the node and link materials in `src/main.js`, driven by a small tween in the render loop. The card is a pure renderer in `src/render.js` styled in `src/style.css`; the render loop toggles an `open` class on the Contact section once the door is three-quarters open. The loader gains a `<video>` under the existing constellation canvas.

**Tech Stack:** Vanilla JS, Vite 8, Three.js 0.169 (ShaderMaterial), node --test + happy-dom, ffmpeg for the encode. Spec: `docs/superpowers/specs/2026-09-14-contact-door-and-loader-design.md`.

Run tests with `npm test` from the repo root. Commit after every task with the trailer `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

```js
// tel: href — digits only, local 0 → +972. Empty in → empty out (no dead link).
export const telHref = (s) => {
  const d = String(s || '').replace(/\D/g, '');
  if (!d) return '';
  return 'tel:+' + (d.startsWith('972') ? d : d.replace(/^0/, '972'));
};

// 10 Contact — the card the door hands over. Rows carry --i for the stagger.
export function renderContact(p) {
  const l = p.links;
  const social = [['GitHub', l.github], ['LinkedIn', l.linkedin], ['X', l.x]].filter(([, h]) => h)
    .map(([n, h]) => `<a href="${escAttr(h)}" target="_blank" rel="noopener">${n}</a>`).join('');
  const tel = telHref(l.phone);
  return `${eyebrow('Let’s build something')}
    <article class="card" aria-label="Contact card">
      <header class="card-row card-head" style="--i:0"><h2 class="card-name">${esc(p.name)}</h2><p class="card-role">${esc(p.title)}</p></header>
      <a class="card-row mail" style="--i:1" href="mailto:${escAttr(l.email)}" data-copy-email>${esc(l.email)}<small>click to copy</small></a>
      ${tel ? `<a class="card-row tel" style="--i:2" href="${escAttr(tel)}">${esc(l.phone)}</a>` : ''}
      <div class="card-row social" style="--i:3">${social}</div>
      <footer class="card-row card-foot" style="--i:4">${esc(p.contact.availability)}</footer>
    </article>`;
}
```

### Task 3: The door in the network shaders

**Files:**
- Modify: `src/main.js` — `DRIFT_GLSL` (~line 660), `pmat` (~670), `lmat` (~729), the module's `return` (~775)

- [ ] **Step 1: Add the door GLSL next to `DRIFT_GLSL`**

Directly after the `DRIFT_GLSL` const add:

```js
  // The contact door: vertices near the door axis (a line through uDoorC along
  // uDoorAx) are pushed radially outward as uDoor rises 0→1. Soft edge at R;
  // nothing beyond R moves. `d` (distance to the axis) is handed back so the
  // link fragment can thin strands inside the door instead of stretching them.
  const DOOR_R = 34.0;
  const DOOR_GLSL = `uniform float uDoor; uniform vec3 uDoorC,uDoorAx;
    vec3 doorPush(vec3 p, out float d){
      vec3 r=p-uDoorC; vec3 perp=r-uDoorAx*dot(r,uDoorAx); d=length(perp);
      float w=uDoor*smoothstep(${DOOR_R.toFixed(1)},0.0,d);
      return p+(perp/max(d,0.001))*w*${(DOOR_R * 1.3).toFixed(1)}; }`;
```

- [ ] **Step 2: Wire the node material**

In `pmat`'s `uniforms` add `uDoor: { value: 0 }, uDoorC: { value: new THREE.Vector3() }, uDoorAx: { value: new THREE.Vector3(0, 1, 0) }`.
In its `vertexShader`, after `${DRIFT_GLSL}` add `${DOOR_GLSL}`, and change the first line of `main()` from
`vec3 p=drifted(position,aAmp,aFre,aPha,uTime,uDrift);` to
`float dd; vec3 p=doorPush(drifted(position,aAmp,aFre,aPha,uTime,uDrift),dd);`.

- [ ] **Step 3: Wire the link material**
