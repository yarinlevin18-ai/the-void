# Sketches

Standalone experiments from June and July 2026, made before and during the first
builds of The Void: the living void, the nebula, the loader and the opening
wordmark, a water ripple, the wave ribbon, and two font specimens.

None of it ships. Vite builds only `index.html`, and several of these ideas were
later dropped on purpose (the wave ribbon, the cursor effects, the Adobe Fonts
typefaces). Where a shader or a set of values was ported into the site, a comment
in `src/main.js` points back to the file here.

Each page opens on its own. three.js comes from a CDN through an import map, and
most pages load an Adobe Fonts kit. `demo-hero-screens.html` shows no images: the
hero screens and their assets were deleted on 29 Sep 2026.
